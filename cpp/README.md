# C++: variables to object-oriented programming

Begin with `01_variables.md` and work through the numbered notes in order. Each file introduces a small group of ideas with examples. Examples are written for C++17 unless noted.

## Learning path

1. [Variable names, declarations, and initialization](01_variables.md)
2. [Types, constants, and conversions](02_types_and_constants.md)
3. [Operators and expressions](03_operators.md)
4. [Input, output, and decisions](04_input_output_and_conditions.md)
5. [Loops](05_loops.md)
6. [Functions and scope](06_functions.md)
7. [Arrays, strings, and vectors](07_collections.md)
8. [References and pointers](08_references_and_pointers.md)
9. [Classes and objects](09_classes_and_objects.md)
10. [Encapsulation, constructors, and access control](10_encapsulation_and_constructors.md)
11. [Inheritance](11_inheritance.md)
12. [Polymorphism](12_polymorphism.md)
13. [Abstraction and putting OOP together](13_abstraction_and_review.md)

For a deeper intermediate-level treatment of the same progression, read [INTERMEDIATE_GUIDE.md](INTERMEDIATE_GUIDE.md). The `examples/` folder contains standalone programs; for instance, compile from this directory with `g++ -std=c++17 -Wall -Wextra -pedantic examples/05_classes.cpp -o classes` and run `./classes` (macOS/Linux) or `classes.exe` (Windows).
